# Shared

这一层用于约束前端和模型之间的“共同语言”。

## 应该放什么

- `schemas/`：接口入参和出参的 JSON Schema
- `types/`：TypeScript 或其他共享类型
- `constants/`：状态、步骤类型、图表类型、实验标签
- `utils/`：纯数据处理工具，不能依赖具体业务框架

## 应该避免什么

- 不要把前端页面逻辑写进来
- 不要把模型训练逻辑写进来
- 不要让这里依赖某一个具体应用

## 推荐原则

- 所有接口字段先在这里定义
- 字段一旦对齐，前后端各自开发
- 变更字段时，优先改 `shared/` 再同步上下游
